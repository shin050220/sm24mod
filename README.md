# SM24 ニュース

スマホゲーム「Soccer Manager 2024」のキャリアで起きた試合・移籍・成績・順位を、Claude がサッカーニュース風の記事にする個人用 Web アプリです。PC でもスマホでも使えます。

## できること

- **ホーム（ダッシュボード）**：自分のクラブの順位・勝敗・勝点・直近の結果・連勝などの記録、順位表、得点／アシストランキング、最近の移籍、最新ニュースを一画面で見られます。
- **かんたん入力**：ホームの「＋試合」「＋移籍」から、自分のクラブ視点で数項目だけ入れて登録できます。
- **自動で記事化（無料）**：データを追加すると、テンプレートで記事が自動で作られます（AI 不要・料金なし）。設定でオフにできます。
- **スクショ取り込み**：SM24 の試合結果・移籍履歴・選手成績・順位表などの画面のスクショを選ぶと、AI が読み取ってデータにします（保存前に確認・修正できます）。
- **手入力**：試合・移籍・選手成績・順位表を自分で入力・編集できます。
- **記事作成**：データを選んで、テンプレ（無料）か AI（有料）で記事にできます。AI の場合は文体（スポーツ紙／一般紙／海外メディア風／速報／辛口コラム）と長さを選ぶと記事ができます。記事にしたデータには「記事化済」の印が付きます。
- **ニュース一覧**：カテゴリ別の表示、検索、コピー、削除ができます。
- **バックアップ**：JSON で書き出し・読み込みができます（PC とスマホの間でデータを移すときにも使えます）。

## 使い方

1. アプリの「設定」で監督しているクラブ・シーズンを入力します。
2. ホームの「＋試合」「＋移籍」でデータを入れると、記事が自動で「ニュース」に載ります。
3. スクショ読み取りや AI 記事を使いたいときだけ、[Anthropic Console](https://console.anthropic.com/) で API キーを作って設定に入れます（使った分だけ料金がかかります。Haiku 5.5 なら1回1円未満が目安）。

データと API キーは、使っているブラウザの中（localStorage）にだけ保存されます。サーバーはありません。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ に出力
```

## 公開（GitHub Pages）

`main` ブランチに push すると `.github/workflows/pages.yml` が `dist/` を GitHub Pages に公開します。
初回はリポジトリの Settings → Pages → Source で「GitHub Actions」を選んでください。
